# ArbolEduCYM

ArbolEduCYM es una aplicación web educativa para estudiar árboles binarios de manera visual, práctica y teórica. Permite insertar, eliminar, buscar, recorrer y evaluar conocimientos mediante un mini cuestionario.

## Objetivo

Ayudar a estudiantes de tercer semestre o posteriores a comprender conceptos clave de árboles binarios, como nodos, niveles, altura, recorridos y eliminación de elementos.

## Archivos principales

- `index.html`: estructura de la interfaz.
- `styles.css`: estilos visuales modernos y responsivos.
- `script.js`: lógica del árbol, animaciones y cuestionario.

## Requisitos

- Navegador moderno (Chrome, Edge, Firefox o Safari).
- Conexión local no necesaria, ya que toda la aplicación se ejecuta en el navegador.

## Ejecución rápida

1. Descarga o descomprime la carpeta `ArbolEduVCT`.
2. Abre `index.html` en un navegador.
3. Usa los controles para insertar, buscar, eliminar y recorrer el árbol.

## Funcionalidades principales

- Inserción con validación.
- Solo enteros o letras por árbol; no acepta decimales ni mezcla de tipos.
- El árbol y las colecciones auxiliares se manejan con nodos y listas enlazadas, sin usar arreglos.
- Acepta valores repetidos y los ubica a la izquierda cuando encuentra un igual.
- Eliminación con los tres casos clásicos.
- Búsqueda paso a paso.
- Recorridos preorden, inorden y postorden.
- Análisis del árbol completo y de cada subárbol: conteo total, conteo de la raíz y sus hijos directos, recorridos, altura, grado, orden y nivel.
- Teoría dinámica con glosario de relaciones entre nodos, ramas, orden, grado, nivel, altura y clasificación de árboles binarios.
- Quiz con 15 preguntas por intento sobre conceptos y recorridos, con calificación final.

## Nota

La aplicación no usa bibliotecas externas ni servicios de terceros. Todo el funcionamiento se implementa con HTML5, CSS3 y JavaScript puro.
